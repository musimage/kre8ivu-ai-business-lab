# KRE8ivU AI Business Lab

Responsive static pilot site for GitHub + Cloudflare Pages.

Pages: /, /about/, /program/, /learn/, /contact/.

## Deploy

1. Create a GitHub repository and upload this folder's contents to its root.
2. In Cloudflare: Workers & Pages -> Create application -> Pages -> Connect to Git.
3. Select the repository, choose None for framework preset, leave the build command blank, and deploy from the root.
4. In Pages, add the custom domain. Add only the DNS record Cloudflare provides in HostGator.

## Keep Google Workspace email intact

Keep all existing Google Workspace MX, SPF, DKIM, and DMARC records. Do not replace mail records when adding the website record. Review any DNS import before changing nameservers, then verify mail delivery.

The contact form is a non-submitting placeholder until the approved intake destination is selected. Confirm dates, capacity, refund terms, and enrollment process alongside the displayed $597 price.
